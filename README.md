# Misión Cualitativa

Simulador del proceso de investigación de mercados cualitativa (SIM II · Mercadotecnia, UTH).
Proyecto "De Sonora para el mundo" · Dr. Raúl Guadalupe Paredes Barceló.

**App en línea:** https://rwalls81.github.io/mision-cualitativa/

Toda la aplicación vive en `index.html`. Para activar o bloquear misiones,
editar la línea que empieza con `window.MC_CONFIG` (la zona docente de la app
prepara la línea exacta a pegar).
